
## Open Project

Use **Vivado 2024.1** and open:

```text
vivado/CNN_on_FPGA_pj/CNN_on_FPGA_pj.xpr
```

## Generate Bitstream and XSA

Run:

```text
Validate Design
Generate Output Products
Generate Bitstream
File → Export → Export Hardware → Include bitstream
```

Generated folders are not tracked in Git and can be recreated by Vivado.
