# Files to Keep for an Openable Vivado Project

For this repository, the openable Vivado project is stored in:

```text
vivado/project/CNN_on_FPGA_pj/
```

Keep:

```text
CNN_on_FPGA_pj.xpr
CNN_on_FPGA_pj.srcs/
```

Do not commit:

```text
CNN_on_FPGA_pj.cache/
CNN_on_FPGA_pj.gen/
CNN_on_FPGA_pj.hw/
CNN_on_FPGA_pj.ip_user_files/
CNN_on_FPGA_pj.runs/
CNN_on_FPGA_pj.sim/
CNN_on_FPGA_pj.tmp/
.Xil/
*.bit
*.xsa
```

Those folders/files are generated by Vivado and can be recreated.

If you want to share a prebuilt `.bit` or `.xsa`, attach them to a GitHub Release instead of committing them in the repository.
